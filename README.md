# Image Toolkit 🖼️

A lightweight, Python-based CLI application for image viewing, manipulation, conversion, and metadata analysis. Powered by **Pillow (PIL)**, this toolkit offers 20 essential image-processing features right from your terminal.

---

## 🚀 Features

* **EXIF & Location Viewer:** Extract detailed camera metadata and GPS coordinates (if available).
* **Image Stats & Color Palette:** View dimensions, format, color mode, and top 3 dominant colors.
* **ASCII Art Converter:** Turn any image into stylized text art.
* **Text Watermark Generator:** Overlay customized centered text watermarks.
* **Format Converter:** Effortlessly convert between PNG, WEBP, JPEG, and BMP formats.
* **Quality Compression:** Compress JPEGs to reduce file size based on custom quality settings.
* **Color Filters & Effects:** 
  * Grayscale, Sepia Tone, Invert Colors (Negative), and Red Channel Extraction.
  * Gaussian Blur, Sharpen, and Edge Detection filters.
* **Transformations:** Resize, crop, rotate (90°, 180°, 270°), flip/mirror, and thumbnail generation (150×150).
* **Adjustments & Decor:** Brightness and contrast adjustments, plus custom border creation.
